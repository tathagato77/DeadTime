# ⚡ Dead Time — Micro-Learning Android App

> **Master hard skills in 2-minute windows.** Stop doom-scrolling your downtime and build real knowledge on the go.

## 🚀 About the Project
**Dead Time** is a lightweight, high-efficiency micro-learning Android application built to help users learn and retain valuable skills during small intervals of free time throughout the day. 

Developed independently by **Mango Software**, the app focuses on clean UI, lightning-fast execution, and distraction-free education.
